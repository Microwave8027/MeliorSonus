# Modification Protocol
When you need to modify the OSMD Display:
1. Transcribe kotlin logic into JavaScript and modify the OSMD webview accordingly
2. Make sure you read the github documentation
3. Any additional notes that only show when the user is on that page of sheet music must be written in JavaScript through a function to display it.
